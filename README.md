# coolcard

把一張圖變成一張數位酷卡：有厚度、會自己轉、會反光。也是線上名片——互相掃 QR 就能交換，粉絲可以收集創作者的認親卡。

場域：同人場次、展會、市集。

## 這個 repo 裡有什麼

| 檔案 | 是什麼 | 怎麼看 |
| --- | --- | --- |
| `coolcard-prototype.html` | 可點的前端原型，三條流程都走得完 | 用瀏覽器直接開，不用起伺服器 |
| `閃卡規格書.html` | MVP 規格 V3（材質、比例、QR、列印、工作清單） | 用瀏覽器直接開 |

原型不接後端。卡冊存在瀏覽器的 localStorage，換瀏覽器或用不同網址開就是另一份資料。

## 三條流程

1. **創作者做卡＋分享** — 上傳 → 選卡框 → 裁切 → 選材質 → 填資訊 → 編輯鑰匙 → 發布 → 出示 QR／曬卡圖
2. **接收者收卡＋卡冊** — 掃到卡片 → 開卡動畫 → 收進卡冊 → 卡冊／詳情
3. **列印** — 選紙（ibon 4×6 或 A4）→ 平面化預覽 → 下載 JPG／PDF → 7-11 列印步驟

## 已經定案的規格

- **比例與尺寸**：1:1（63×63mm）、3:4（63×84mm）、2:3（58×87mm），都是直式
- **材質**：紙質（光滑卡紙／紋理紙／半透卡）× 效果（霧面／亮面／閃閃）× 閃法（流光／星砂／格紋），共 15 種組合
- **卡片會自己轉**，不靠滑鼠也不靠手機傾斜；同一個畫面只有一張卡在轉
- **列印**：只支援 ibon 的 4×6 專用紙（對折成雙面卡）與 A4 厚紙（雙面列印）
- **兩條連結**：分享連結 `/c/<code>`、編輯連結 `/e/<code>#k=<key>`，金鑰放在 `#` 後面不會進伺服器紀錄
